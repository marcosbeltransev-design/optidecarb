# Install OptiDecarb like a desktop site on Windows

Public app: https://optidecarb.streamlit.app

OptiDecarb remains a Streamlit web application. It is **not claimed as a full native PWA**. Modern browsers can still install many sites into their own window and pin them to the Windows taskbar.

## Microsoft Edge

Typical flow:

1. Open `https://optidecarb.streamlit.app`.
2. Open the `…` menu.
3. Choose **Apps**.
4. Choose **Install this site as an app**.
5. Name it **OptiDecarb**.
6. If Edge offers the option, choose **Pin to taskbar**.

## Google Chrome

Depending on the Chrome version, look for one of these options:

- **Install page as app**; or
- **Create shortcut** and, when available, **Open as window**.

Browser menu names can change over time. The OptiDecarb favicon / page icon is included so the installed-site shortcut is easier to recognize where the browser uses the site icon.
