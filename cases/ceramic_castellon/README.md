# Castellón representative ceramic case

This directory contains the frozen **`ceramic-castellon-v1`** public-data-calibrated electrical case used by Industrial Energy Lab v1.0.

- `case_config.json` — explicit case parameters and source links.
- `sources.json` — provenance registry distinguishing external data, derived values, proxies and assumptions.
- `data/` — deterministic 8,760-hour offline case snapshots.
- `metadata/` — dataset versions, statistics and transformation notes.
- `results/` — frozen regression outputs and selected sensitivity results.
- `CASE_STUDY.md` — readable case-study narrative and limitations.

> This representative case is constructed from public sector data and explicit modelling assumptions. It does not reproduce the operations, costs or energy consumption of any individual ceramic company.

> Electrical subsystem only. Thermal process energy, kilns, dryers and natural-gas consumption are outside v1 scope.
